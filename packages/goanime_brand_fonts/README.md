# GoAnime brand fonts

Deterministic production subset used by GoAnime Mobile to avoid runtime font downloads and cold-start font swaps.

Sources are pinned and copied without modification:

- Epilogue: `Etcetera-Type-Co/Epilogue@76bd97a82f0105535fb06e6940f2140b2c1a660c`
- Manrope: `aaronbell/manrope@6f81ebecdf65e4463b798cc07b16a4f8d5216917`

Both families are distributed under the SIL Open Font License; the upstream OFL files are included in `assets/licenses/`.
